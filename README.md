# Liliscend Portfolio

GitHub Pages用の1ページ型ポートフォリオです。

## 公開方法

1. GitHubで新しいPublicリポジトリを作成
2. `index.html` と `style.css` をアップロード
3. Repository → Settings → Pages
4. Sourceを「Deploy from a branch」
5. Branchを `main` / `root` に設定
6. Save

数分後、GitHub PagesのURLで公開できます。

## 差し替える場所

`index.html` 内の以下を実際のリンクに差し替えてください。

- noteプロフィール
- 専門スキル・実績紹介記事
- 自己紹介記事
- Amazonほしいものリスト

現在はnote DMを問い合わせ窓口にしています。
